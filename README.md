# 坦克大战 · Tank Battle

一个用纯 HTML + CSS + JavaScript（Canvas）实现的网页版坦克大战游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- 控制你的绿色坦克，消灭场上所有红色敌方坦克即可进入下一关。
- 保护屏幕下方的**基地（旗帜）**：一旦被子弹击中，游戏立即结束。
- 你有 3 条生命，被敌方击中会损失一条并短暂重生。
- 关卡会不断升级，敌人越来越多、越来越快。

## 操作

| 操作 | 按键 |
| ---- | ---- |
| 移动 | `W A S D` 或方向键 |
| 射击 | `空格`（可长按连射） |
| 暂停 / 继续 | `P` |
| 静音 | `M` |
| 开始 / 重开 | `回车` 或点击按钮 |

## 地形

- 🧱 **砖墙**：可被子弹摧毁。
- 🛡️ **钢墙**：子弹无法摧毁。
- 🌊 **水面**：坦克无法通过，子弹可以飞过。
- 🌲 **树林**：坦克和子弹可以穿过，但会被树冠遮挡（躲藏点）。

## 运行方式

直接用浏览器打开 `index.html` 即可，也可以起一个本地服务器：

```bash
# 方式一：Python
python -m http.server 8000

# 方式二：Node.js
npx serve
```

然后访问 `http://localhost:8000`。

## 技术说明

- 纯前端，单文件 `index.html`，无第三方依赖。
- 使用 Canvas 2D 渲染，`requestAnimationFrame` 游戏循环。
- 音效使用 Web Audio API 实时合成，无需音频文件。
- 关卡地图以左右镜像方式生成，保证对称布局。
